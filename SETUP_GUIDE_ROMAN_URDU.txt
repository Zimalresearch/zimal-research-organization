A responsible adult/authorized organization representative should handle legal registration and financial accounts.

SUPABASE SETUP
--------------
1. Create a Supabase project using an adult/authorized account.
2. Open Project Settings > API. Copy the Project URL and PUBLIC anon/publishable key.
3. Open config.js and replace:
   YOUR_SUPABASE_PROJECT_URL
   YOUR_SUPABASE_PUBLIC_ANON_OR_PUBLISHABLE_KEY
   with the values from Supabase. Use only the public browser key.
4. In Supabase Authentication settings, turn OFF public sign-ups.
5. In Authentication > Users, create the one administrator account with a strong password.
   Do not share the password with anyone.
6. Open SQL Editor and run the contents of supabase-setup.sql.
7. In SQL Editor, replace YOUR_ADMIN_EMAIL in the final commented INSERT statement
   with the exact administrator email, remove the leading -- from both lines, and run it:
   insert into public.zro_admins (user_id, email)
   select id, email from auth.users where email = 'your-admin-email@example.com';
8. Open admin.html on your site and sign in with that admin email/password.
9. Upload a test image, then check the public index.html gallery.

LOCAL TEST
----------
For best results, run the folder using a local web server rather than file://.
If Python is installed, open Command Prompt in this folder and run:
   python -m http.server 8000
Then open:
   http://localhost:8000

MEDIA
-----
Images: JPEG, PNG, WEBP, GIF up to 8 MB.
Videos: MP4, WEBM, MOV/QuickTime up to 40 MB.
Use photos/videos only when you have permission. Take extra care with children's privacy:
obtain parent/guardian consent and avoid publishing children's full names, school details,
home addresses, or other identifying information.

PUBLISHING
----------
Upload the folder contents to a static hosting provider such as Cloudflare Pages or Netlify.
Hosting providers have their own limits and terms; no hosting service should be described as
unlimited. This website does not automatically create an organization registration or
charitable status.
